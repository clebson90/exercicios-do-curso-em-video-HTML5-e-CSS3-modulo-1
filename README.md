# ⚡ Exercícios de Linguagem C — 2º Semestre de ADS

Repositório criado para armazenar as atividades, desafios e exercícios desenvolvidos na linguagem **C** durante as aulas do 2º semestre do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

---

## 📌 Sobre o Repositório

Este repositório serve como registro da minha evolução prática em lógica de programação, sintaxe estruturada e fundamentos da ciência da computação utilizando a linguagem C, com foco no entendimento de estruturas de dados e gerenciamento de memória.

---

## 📚 Conteúdos e Tópicos Abordados

- **Fundamentos:** Entrada e saída de dados (`scanf`, `printf`), variáveis, tipos primitivos (`int`, `float`, `char`) e operadores aritméticos/lógicos.
- **Estruturas Condicionais:** Tomadas de decisão e controle de fluxo com `if`, `else` e `switch-case`.
- **Estruturas de Repetição:** Laços de repetição usando `for`, `while` e `do-while`.
- **Vetores e Matrizes:** Manipulação de estruturas de dados unidimensionais (arrays) e multidimensionais.
- **Funções e Ponteiros:** Modularização de código, passagem de parâmetros por valor/referência e noções de gerenciamento de memória.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C
- **Compilador:** MinGW (configurado via extensão C/C++ do VS Code)
- **Ambiente de Desenvolvimento:** VS Code
